# WyroBase/.github

The [WyroBase](https://github.com/WyroBase) organization profile. `profile/README.md` is what GitHub shows on the org page.

The images in `profile/assets/` are rendered from the HTML in `design/`. Edit the HTML, then run `sh design/render.sh` (needs Google Chrome). The terminal image is a real `wyro-check` run, and the source file says how to reproduce it. Re-run the check before changing any number in it.
